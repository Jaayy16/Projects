Project Descriptions:

Expanse Reclamation:

A chess board style tower defence game where the player must reach a certain point on the board to complete a level while fending off hostile waves.

Mobile Game:

A Godot Game with four games inside, two simple maths games, a 'Three-men's Morris' game with multiplayer support through a python flask server, and a 'Hey that's my fish' game with multiplayer support through the same flask server.

Tower Defence:

A 2D Tower Defence game made in Raylib C++ where players clear waves acquiring currency and placing towers and buying upgrades as waves progressively get harder (This project, like Physics Game were made with priority given to header files and pointers for handling of variables on larger projects).

Procedurally Generated Dungeon Crawler:

A Procedurally generated dungeon crawler with seed based generation, enemies, decorations, biomes, tile-variance, room sizes and shapes are all procedurally generated based the seed given.

Physics Game:

A 2D Physics game made in Raylib C++ where players must progress through two levels, the first having the objective to aim and shoot a ball at a target, the second level requiring them to knock down a house to complete the level and beat the game (This project, like Tower Defence were made with priority given to header files and pointers for handling of variables on larger projects).

Game Review Chatbot:

Made with python to scrape IGN and steam Revies of any given title, Converting the steam scores into an average which can be compared to the IGN score, and listing the top reviews from steam along with the most common words used.
